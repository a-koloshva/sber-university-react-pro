# Домашнее задание №5 для курса Разработка на ReactJS: продвинутый уровень

Основа проекта взята из лекции.

Добавлено:

- Компонент ClickTimer

- Компонент PreviousInput

- Компонент FocusTracker

- Компонент DebouncedLogger с useRef

- Компонент WebSocketLogger

Все работает корректно. Проект стабилен.

## Как запустить проект

1. Перейдите в нужную папку:

```bash
cd lesson-05
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите проект:

```bash
npm run dev
```
