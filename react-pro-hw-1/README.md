# Домашнее задание №1 для курса Разработка на ReactJS: продвинутый уровень

## Что выполнено

- Создан проект по FSD, настроены ESLint и Prettier с конфигурацией, отражающей принципы FSD.

- Реализована сущность **Task** в слое entities/.

- Реализован компонент **taskList** в слое features/, содержащий компонент **TaskList**, **TasksFilters** и хук **useTasks**.
    - В хуке **useTasks** реализована логика удаления и фильтрации задач, а также хранение списков задач и фильтров.
    - В компоненте **TasksFilters** реализовано отображение кнопок для фильтрации.

- Реализован и подключен виджет **TaskWidget** в слое widgets/, реализующий визуальную обертку над **TaskList** и **TasksFilters**, фильтрацией и логикой управления задачами.

- Создана страница **TaskPage** в слое pages/, которая отображает список задач с фильтрацией.

- Кнопка фильтрации **FilterButton** вынесена в shared/ui и используется внутри компонента **TasksFilters**.

## Как запустить проект

1. Перейдите в нужную папку:

```bash
cd react-pro-hw-1
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите проект:

```bash
npm run dev
```
