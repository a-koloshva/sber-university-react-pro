Основа проекта взята из лекции.

Добавлено:

- Компонент ProtectedRoute и useAuth

- Страница LoginPage

- Защищенная страница ProfilePage

- Страница PublicPage + автоматический выход

Все работает корректно. Проект стабилен.

## Как запустить проект

1. Перейдите в нужную папку:

```bash
cd lesson-06
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите проект:

```bash
npm run dev
```
